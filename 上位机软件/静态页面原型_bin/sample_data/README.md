# Sample Data

This folder is intentionally not committed with real RGB-D images or point-cloud captures.

Place local datasets here when running the analyzer:

```text
sample_data/
  your_dataset/
    color/
      000000.png
      000001.png
    depth/
      000000.png
      000001.png
```

The application pairs RGB and depth images by sorted filename order. The dataset can also be selected from any local folder through the UI.
