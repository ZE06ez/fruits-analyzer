# Sample Data

This folder is kept as an optional place for local sample captures.
The application no longer ships with built-in demo image folders.

Place a captured fruit sample folder here, or select it from any local path in the UI:

```text
sample_data/
  sample_001/
    rgb/
      rgb_000.png
    multispectral/
      450.png
      520.png
      660.png
      730.png
      850.png
    calibration/
      dark/
      white/
```

`rgb` stores images from the color camera. `multispectral` stores single-band grayscale images captured by the monochrome camera through different filters.
