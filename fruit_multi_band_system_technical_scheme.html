fruit_multi_band 多光谱蓝莓检测样机技术方案

版本：v1.0 草案；目标：采集蓝莓 RGB 图像与多光谱图像，建立 SSC、TA 与 SSC/TA 糖酸比预测模型，并为后续分选装置开发提供硬件基础。

检测对象3-5颗蓝莓/样品
多光谱范围400-1000 nm
滤光片转轮25mm滤光片，16孔
主控架构电脑 + STM32

1. 系统总体架构

整机采用“电脑负责图像采集与模型处理，STM32负责执行机构与状态采集”的分工。两个相机均直接连接笔记本电脑，STM32不处理图像，只负责滤光片转轮、光源、风扇、升降门、称重和传感器状态。

电脑上位机
  ├─ USB/GigE → RGB彩色相机
  ├─ USB/GigE → 黑白工业相机
  └─ USB串口 → STM32主控板
                 ├─ CL57C闭环步进驱动器 → 57闭环步进电机 → 16孔滤光片转轮
                 ├─ SSR1/SSR2 → 12V100W卤钨灯1/2
                 ├─ MOS模块 → 24V白色LED条形灯1/2
                 ├─ MOS/继电器 → 24V散热风扇2-3个
                 ├─ 电机驱动/H桥 → 升降门电机
                 ├─ GPIO输入 → HOME槽型光电、门限位、急停、门磁
                 └─ HX711/ADC/串口 → 称重、温度等传感器
相机由电脑直接控制，采图、曝光、增益、白平衡、保存路径和样品编号均由上位机管理。STM32只需要在“硬件已到位、灯已稳定、转轮已定位”后向电脑返回状态。

2. 电源模块

整机低压电源分为 48V、24V、12V 和 5V 四类，避免不同负载互相干扰。220V 输入侧后续整机联调时建议通过 2P C10A 空气开关或漏保空开进入设备内部。

电源用途规格建议注意事项
48V DCCL57C闭环步进驱动器LRS-200-48，约48V/4.2A/200W只供转轮电机，不接灯和STM32
12V DC2个12V100W卤钨灯12V/33A，约400W两个灯并联，每灯独立SSR控制，错峰启动
24V DC风扇、LED、传感器、门电机、控制模块LRS-200-24，约24V/8.8A/200W控制电源和灯电源分开
5V DCSTM32、小模块、HX711、TTL模块24V转5V降压模块，5A，1-2个5V由24V降压获得，注意共地策略
AC 220V所有开关电源输入、笔记本适配器三芯电源线，PE接地强弱电分区，220V端子加保护罩

3. 上位机与STM32通讯模块

电脑与STM32通过USB串口通信。建议使用固定6字节协议，简单、稳定、易于调试。

固定帧格式：AA 55 CMD P1 P2 SUM
SUM = (AA + 55 + CMD + P1 + P2) & 0xFF
CMD功能P1P2说明
0x01电机使能0/101使能，0失能
0x02转轮HOME00寻找原点传感器
0x03转到孔位1-16速度档P2: 0慢，1中，2快
0x04下一个孔位00转轮顺序切换到下一孔
0x05卤钨灯控制灯号1-20/1每灯一路SSR
0x06RGB LED控制灯号1-20/1彩色相机专用白光LED
0x07全部光源关闭00关闭卤钨灯和LED
0x08风扇控制风扇号1-40/1用于散热控制
0x09升降门控制0/1/200停，1开，2关
0x0A读取重量00返回称重数据
0x0B读取温度00返回箱内温度/灯区温度
0x0C读取状态00返回孔位、灯、门、报警等
0x0D清除报警00清除驱动器或系统报警
0xFF急停00立即关灯、停门、停电机

4. 相机模块

RGB彩色相机

用于采集蓝莓外观图像，包括颜色、果粉、大小、纹理和缺陷信息。由电脑直接控制，光源为普通白色LED条形灯。

建议5MP左右工业彩色相机，手动曝光、手动白平衡、C口镜头。

黑白多光谱相机

用于采集通过16孔滤光片转轮后的灰度多光谱图像。由电脑直接控制，光源为12V100W卤钨灯。

建议2-5MP黑白工业相机，无IR-cut，支持Mono8/Mono12，400-1000nm响应。

6. 卤钨灯多光谱照明模块

黑白多光谱通道使用2个12V100W低压卤钨灯杯，提供400-1000nm连续光谱照明。两个灯并联供电，但每个灯单独一路DC-DC SSR控制。

部件数量规格说明
卤钨灯杯212V，100W，标称400-2500nm左右对称布置
12V电源112V，33A，约400W专供两盏卤钨灯
SSR2DC-DC，DD220D40，40A每个灯一个SSR
SSR散热片2配导热硅脂SSR底面贴合散热片
端子排2TC3006，30A，6位12V+和12V-分开
灯线若干主线2.5mm²，支线1.5mm²或1.27mm²高温线灯杯附近用硅胶编织高温线更好
匀光片2-3100×100×1mm，600目单面磨砂石英片抛光面朝灯，磨砂面朝样品
 
12V电源 V+ → 12V+端子排 → 灯1+ / 灯2+
灯1- → SSR1 输出+ → SSR1 输出- → 12V电源 V-
灯2- → SSR2 输出+ → SSR2 输出- → 12V电源 V-

STM32 GPIO_LAMP1 → SSR1 输入+
STM32 GND        → SSR1 输入-
STM32 GPIO_LAMP2 → SSR2 输入+
STM32 GND        → SSR2 输入-
卤钨灯属于阻性负载，但冷启动冲击电流高。程序应采用错峰启动：先开灯1，延时500-1000ms，再开灯2。两个灯不能串联，必须并联。

7. RGB LED照明模块

RGB彩色相机使用普通白色LED条形光源，与卤钨灯轮流打开，避免卤钨灯偏黄色温影响RGB颜色。

项目建议说明
LED类型24V白色机器视觉条形光源左右各1根，色温5000-6500K
功率单根10-30W根据视场和亮度调节
控制10A MOS模块或30A MOS模块支持3.3V触发，PWM调光更好
电源24V控制电源不要和12V卤钨灯正极混接
 
24V电源 V+ → LED+
LED- → MOS LOAD-
MOS GND → 24V电源 V-
STM32 GPIO_LED → MOS IN
STM32 GND → MOS GND

8. 散热风扇模块

建议装2-3个散热风扇，结构上预留4个风扇位。风扇主要服务卤钨灯散热、SSR/电源散热和箱体温度控制。风道必须做遮光处理，避免外界光漏入暗箱。

风扇建议规格控制方式安装位置
FAN124V，120mmMOS控制，可常开灯区排风
FAN224V，120mmMOS控制，可常开电控区/SSR散热
FAN324V，80mm或120mm可选箱体辅助进风/排风

建议风扇先随系统启动常开。若加入温度传感器，可设置温度阈值，例如灯区超过35°C开启强制散热，超过45°C禁止继续采集并报警。

9. 升降门与安全传感器模块

升降门不要求高精度，可采用齿轮条 + 直流减速电机 + H桥驱动模块。必须设置上限位和下限位，防止电机堵转。

部件连接到STM32说明
门电机H桥驱动输入控制正转、反转、停止
上限位GPIO输入门到顶后立即停止
下限位GPIO输入门到底后立即停止
急停按钮GPIO输入 + 硬件断电回路触发后关灯、停电机、停门
门磁/门状态GPIO输入门未关闭时禁止采集

10. 样品称重与生化标签模块

称重模块用于记录每组蓝莓样品质量，便于后续TA计算和样本管理。每份样品建议为3-5颗蓝莓。

指标方法备注
SSC数显折射仪取同一份匀浆少量汁液测Brix
TAGB 12456-2021，总酸/可滴定酸NaOH滴定，pH计终点法，按柠檬酸计
糖酸比SSC / TA作为蓝莓风味分级关键标签
可选酸组分HPLC/离子色谱重点考虑柠檬酸、奎宁酸、苹果酸

11. 开机启动顺序

1. 合上220V总开关
2. 24V/48V/12V电源上电
3. STM32自检
4. 风扇启动
5. 转轮HOME校准
  1. 检查急停、门状态、限位、HOME传感器是否正常。
  2. STM32关闭所有灯，确保卤钨灯和LED都处于关闭状态。
  3. 启动风扇，建议灯区风扇先运行10-30秒。
  4. 电机使能，转轮低速寻找HOME槽型光电开关。
  5. HOME触发后，将当前孔位设为1号孔，并根据机械偏移补偿到1号滤光片中心。
  6. 电脑连接两个相机，加载曝光参数、保存路径和样品编号。
  7. 电脑向STM32读取状态，确认“READY”后开始采集。

12. 单个样品采集流程

建议每个样品先拍RGB，再拍多光谱。RGB使用LED，黑白多光谱使用卤钨灯，两类光源互锁，不能同时打开。

步骤1：放入样品，关闭升降门
步骤2：电脑发送 READ_STATUS，确认门关闭、转轮已HOME、无报警
步骤3：关闭全部光源
步骤4：打开RGB LED，等待100-300ms
步骤5：彩色相机采集RGB图像，保存 sample_id_rgb.png
步骤6：关闭RGB LED
步骤7：打开卤钨灯1，延时500-1000ms
步骤8：打开卤钨灯2，预热/稳定3-10s
步骤9：黑白相机依次采集16个孔位或指定波段
       对每个孔位：转轮到位 → 等待500-1000ms → 拍照 → 保存
步骤10：关闭卤钨灯，风扇继续运行
步骤11：取出样品，进入SSC/TA生化测定
步骤12：记录样品编号、图像路径、SSC、TA、糖酸比

14. 白板与暗场校正流程

多光谱成像必须做黑白校正，建议每次实验开始时采集一组白板和暗场，每个滤光片波段都需要对应校正图像。

暗场图像：关闭全部光源，盖镜头或保持暗箱完全遮光，采集 D(lambda)
白板图像：放标准白板，打开对应光源，逐孔采集 W(lambda)
样品图像：放蓝莓样品，逐孔采集 S(lambda)
校正图像：R(lambda) = (S(lambda) - D(lambda)) / (W(lambda) - D(lambda))

16. 安全与调试注意事项

  • 所有开关电源外壳、金属电控板、金属灯架应接PE保护地。
  • 12V、24V、48V端子必须贴清楚标签，禁止混接。
  • 卤钨灯附近不能使用普通塑料件和普通亚克力扩散板。
  • SSR必须配散热片，首次点亮10-20分钟后检查SSR、端子和线缆温度。
  • 风扇风道应做迷宫式遮光，防止外界光漏入暗箱。
  • 程序中应设置光源互锁：RGB LED和卤钨灯不能同时开启。
  • 门未关闭、急停触发、温度过高、电机报警时，禁止采集。
  • 调试阶段先单独测试：电机 → 风扇 → 单灯 → 双灯错峰 → LED → 相机联动。

17. 推荐调试顺序

1. 只调STM32串口协议
2. 调CL57C与转轮HOME
3. 调单个SSR与单灯
4. 调双灯错峰与散热
5. 调RGB LED与相机
6. 做白板/暗场采集
7. 采单个蓝莓样品
8. 连续采10个样品
9. 检查温升和稳定性
10. 批量实验
