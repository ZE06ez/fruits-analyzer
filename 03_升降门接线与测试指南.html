24V升降门（电动推杆）接线与测试指南

已知推杆：24V直流，额定0.2A、最大0.4A；红正黑负伸长，黑正红负缩短。使用XY-160D双路H桥的第1路控制。

机械安全：测试时先拆开推杆与门体的机械连接，或保证门体无夹手、撞机风险。必须准备断电开关。最终设备建议安装“门开到位”和“门关到位”两个限位开关。

1. 功率侧接线

24V开关电源 L/+ ──>（交流输入，按电源说明接线并接保护地PE）
24V开关电源 +V ──> 1A保险丝 ──> XY-160D 绿色端子 V+
24V开关电源 -V ─────────────────> XY-160D 绿色端子 GND/PGND

XY-160D 第1路电机输出 OUT1 ──────> 推杆红线
XY-160D 第1路电机输出 OUT2 ──────> 推杆黑线

未使用的第2路电机输出：悬空，禁止短路

推杆最大仅0.4A，建议电机支路使用约1A保险丝，不采用模块图片中针对大电机给出的10A保险丝。

2. STM32控制侧接线

STM32 3.3V ─────────> XY-160D 信号参考电源“+5V”脚
                     （该模块说明明确：3.3V单片机接3.3V）
STM32 GND ──────────> XY-160D 信号端 GND
STM32 GND ──────────> 24V电源 -V / XY-160D PGND（非隔离模块必须共地）

STM32 GPIO_DOOR_EN ─> ENA1
STM32 GPIO_DOOR_IN1 -> IN1
STM32 GPIO_DOOR_IN2 -> IN2
板上标注“+5V”的引脚在该型号说明中是控制信号参考电源：3.3V STM32应接3.3V。首次上电前仍应对照你收到的实物丝印和卖家说明，禁止把24V接到此脚。

3. 建议控制逻辑

IN1IN2ENA1OUT1/OUT2状态
00任意刹车（本项目停止状态）
11任意悬空/滑行
10PWM正转调速
01PWM反转调速
101全速正转
011全速反转

方向A究竟对应“升起”还是“关闭”，由M1-A/M1-B接线决定。首次测试必须点动确认；若方向相反，可交换推杆红黑线，或在软件中交换IN1/IN2定义。

// 换向必须先刹车，等待至少100 ms
ENA1 = 0;
IN1 = 0; IN2 = 0;  // 真值表定义为刹车
delay_ms(100);
// 然后设置新方向，再使能ENA1

4. 限位开关推荐接线

STM32 GPIO_LIMIT_OPEN  ──┬──> 常闭限位开关 ──> GND
                         └──> GPIO内部上拉（或外接10k上拉到3.3V）

STM32 GPIO_LIMIT_CLOSE ──┬──> 常闭限位开关 ──> GND
                         └──> GPIO内部上拉（或外接10k上拉到3.3V）

采用常闭触点可检测断线：正常未触发为低，触发或断线为高。软件必须同时设置最大运动时间，限位和超时任一条件满足都立即停止H桥。

5. 测试步骤

  1. H桥暂不接推杆，万用表确认24V输入极性和3.3V逻辑参考正确。
  2. 关闭电源，接入推杆并串联1A保险丝；推杆先不连接门体。
  3. ENA1采用低电平上电，确保启动时不动作。
  4. 短时间点动方向A，记录推杆伸长或缩短；再停止至少100ms。
  5. 点动方向B，确认反向正常。
  6. 接入并逐个测试开、关限位；手动触发限位时电机必须立即停止。
  7. 连接门体，低速/短行程测试，测量完整开关门时间并设置超时。
  8. 测试串口：11 01关闭门，11 00升起门，11 02立即停止。
通过标准：方向正确；换向有100ms死区；两个限位可靠；卡住或超时会停机；STM32复位时ENA为低；H桥和推杆无异常发热。

6. 接地说明

STM32可以有独立电源，但由于XY-160D控制输入为非隔离接口，必须将以下三点连接在一起：

STM32 GND = XY-160D信号GND = 24V电源负极/PGND

只连接地，不要把STM32开发板的5V电源与24V直接相连。电机线与相机USB线分开走线。

7. 野火HAL示例代码

Door_Extend();   // 推杆伸长，首次脱离门体点动确认
Door_Stop();     // 先停止
HAL_Delay(100);  // 换向死区
Door_Retract();  // 推杆缩短

Door_Command(0x00); // 升起门，方向需按机械结构校准
Door_Command(0x01); // 关闭门，方向需按机械结构校准
Door_Command(0x02); // 立即停止

完整代码：bsp_actuators.c、bsp_actuators.h；串口示例见main_usage_example.c。

当前示例用于台架点动测试。正式装门后必须增加两个限位开关和动作超时状态机，不能只用固定1500ms控制行程。
