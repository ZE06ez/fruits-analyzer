fruit_multi_band 滤光片转轮电机连接与操控指南

适用对象：STM32F407 开发板 + 3.3V转5V高速隔离/差分模块 + HBS57H蓝色数显闭环驱动器 + 57闭环步进电机 + 16孔滤光片转轮。

项目蓝莓多光谱检测样机
驱动器参考HBS57H V110 手册
转轮方案16孔，22.5度/孔
推荐控制STM32发 STEP/DIR 脉冲

1. 先给结论

推荐方案：电机驱动器用独立 48V DC 开关电源供电；STM32 不直接接 HBS57H 的 PUL/DIR，而是经过 3.3V输入、5V供电、5V差分输出 或 高速光耦隔离输出 模块，再进入 HBS57H 的 PUL+/PUL-、DIR+/DIR-。

HBS57H 手册写明控制信号支持 5V-24V，且无需外串电阻；但 STM32 GPIO 是 3.3V，逻辑输入电流典型约 10mA，所以不要把 STM32 直接硬接到驱动器作为正式方案。

本指南里的“升压模块”指两类东西：

  • 电源模块：例如 220V AC 转 48V DC 开关电源，给 HBS57H 和电机供能。这不是小升压板，建议直接买 48V 开关电源。
  • 信号电平转换模块：把 STM32 的 3.3V 脉冲信号变成 HBS57H 更稳的 5V 差分/隔离信号。这是本电机控制部分真正需要的“升压/转换”。

5. STM32到HBS57H控制信号接线

5.1 推荐接法：5V差分输出

如果你买的是“单端集电极转差分输出”“3.3V输入转5V差分输出”“TTL转差分输出”这类模块，优先按下面接法。

STM32侧 转换模块 HBS57H侧 作用
PA8 / TIM1_CH1 STEP_IN 或 PUL_IN PUL+ / PUL- 脉冲。一个有效脉冲对应电机转过一个细分单位。
PA9 DIR_IN DIR+ / DIR- 方向。改变电平后，至少等待5us再发脉冲。
PB0 可选 ENA_IN ENA+ / ENA- 使能/释放控制。第一版可以不接，ENA悬空。
PB1 输入 报警输入隔离模块 ALM+ / ALM- 读取驱动器报警。第一版可先不接，调通后再加。

为什么推荐差分：滤光片转轮上方有卤钨灯、风扇、电源、SSR等干扰源。差分信号比单端5V更抗干扰，线长一点也更稳。虽然你的脉冲频率不高，但样机内部电磁环境不算干净，差分/隔离是花小钱买省心。

5.2 可选接法：5V单端输出

如果模块只有5V单端输出，没有差分输出，也可以用。HBS57H手册说明控制信号支持5V-24V且无需外串电阻。

接法 HBS57H端子 连接方式 备注
共阴极接法 PUL-、DIR-接GND 5V脉冲输出接PUL+；5V方向输出接DIR+ 适合推挽5V输出模块。
共阳极接法 PUL+、DIR+接+5V 模块NPN/开集电极输出拉低PUL-、DIR- 适合NPN开集电极输出模块。

不要混着接：差分模块就按差分接；单端模块就按共阴极或共阳极接。买模块前让卖家发一张“接步进驱动器PUL/DIR”的接线图，确认输入支持3.3V，输出是5V或24V。

7. HOME原点传感器接线

滤光片转轮不要只依靠“累计旋转”长期运行。每次开机先HOME，之后再按孔位累计旋转。这样即使断电、手动碰到转轮、丢脉冲、装配偏差，都能回到明确参考点。

传感器类型 供电 输出接STM32 建议
5V槽型光电开关 5V + GND 输出接STM32输入脚，例如PC13，上拉到3.3V 最简单，适合桌面样机。
24V NPN槽型光电开关 24V + 0V 通过光耦输入模块或分压保护后接STM32 工业抗干扰更好，但不要把24V直接进STM32。

机械布置：在转轮边缘做一个挡片或缺口；挡片进入槽型光电开关时产生HOME信号。HOME点不一定就是滤光片1完全对准相机的位置，通常还需要一个home_offset_pulses偏移量。

8. HBS57H参数设置建议

参数 手册含义 建议值 原因
P-00 细分脉冲数，范围200-60000，出厂1600 第一版用1600 16孔转轮时，每孔正好100脉冲，计算简单、定位足够。
P-01 闭环保持电流，范围1.0-6.0A，出厂2.0A 1.5-2.0A起步 转轮负载不大，先降低发热；若定位不稳再增加。
P-08 脉冲模式：0为脉冲+方向，1为AB正交 0 STM32最容易实现，代码简单。
P-09 运行模式：0脉冲模式，1内部位置模式，2速度模式 0 让上位机/STM32完全控制每次转动角度。
P-13 ENA使能控制极性 第一版先不接ENA 手册建议一般情况下ENA悬空即可，减少使能逻辑误判。
P-18 开闭环选择：0开环，1闭环 1 使用闭环电机，防止丢步后无感知。
P-25 平滑滤波使能 1或保持默认后测试 如果STM32暂时没有加减速，开启平滑更稳；若代码已有平滑加减速，可保持默认。

9. 16孔转轮脉冲计算

已确定结构：16个滤光片孔位，整圈360度，每孔间隔为：

360 / 16 = 22.5度

推荐细分：HBS57H的P-00 = 1600脉冲/圈，则每孔脉冲数为：

1600 / 16 = 100 pulses
P-00脉冲/圈 16孔每孔脉冲 每脉冲角度 适用建议
1600 100 0.225度 首选，简单且足够稳定。
3200 200 0.1125度 更细腻，但脉冲数量翻倍，调试略复杂。
6400 400 0.05625度 一般没必要，除非机械结构非常稳且需要更平滑。

10. STM32操控逻辑

10.1 基本动作

动作 STM32做什么 HBS57H响应 完成条件
设置方向 设置DIR引脚高/低 改变旋转方向 等待至少5us后再发STEP。
走一个孔 发送100个STEP脉冲 电机转动22.5度 脉冲结束后等待500-1000ms稳定。
走到指定孔 计算当前位置到目标孔的孔位差 按最短方向或固定方向转动 更新current_hole。
HOME复位 低速搜索HOME传感器边沿 转轮回到机械零点 再走偏移脉冲，对准滤光片1。

10.2 建议脉冲速度

你不在乎切换时间，每个孔停顿1-2秒完全可以。所以一开始把速度设慢一些，先追求稳定。

阶段 STEP频率 100脉冲耗时 建议
首次调试 50-100 Hz 1-2秒 最稳，肉眼可观察每次转动。
正常采集 200-500 Hz 0.2-0.5秒 足够快，停稳后再拍照。
快速切换 800-1500 Hz 0.07-0.13秒 后期再试，需要加减速。

10.3 伪代码

// 以 P-00 = 1600、16孔转轮为例
#define HOLE_COUNT        16
#define PULSES_PER_REV    1600
#define PULSES_PER_HOLE   (PULSES_PER_REV / HOLE_COUNT)  // 100

int current_hole = 1;
int home_offset_pulses = 0;  // 实装后标定，例如 8、12、-5

void step_once(uint32_t high_us, uint32_t low_us) {
    STEP_HIGH();
    delay_us(high_us);       // HBS57H要求脉冲宽度不小于2.5us
    STEP_LOW();
    delay_us(low_us);        // 低电平宽度不小于2.5us
}

void move_pulses(int32_t pulses, bool dir, uint32_t freq_hz) {
    uint32_t period_us = 1000000UL / freq_hz;
    uint32_t high_us = 20;   // 调试可用20-50us，远大于2.5us
    uint32_t low_us = period_us - high_us;

    SET_DIR(dir);
    delay_us(10);            // DIR提前PUL至少5us

    for (int32_t i = 0; i < pulses; i++) {
        step_once(high_us, low_us);
    }
}

void move_one_hole(bool dir) {
    move_pulses(PULSES_PER_HOLE, dir, 100);  // 100Hz调试很稳
    delay_ms(800);                           // 等转轮机械稳定再拍照
}

void goto_hole(int target) {
    if (target < 1 || target > HOLE_COUNT) return;

    int delta = target - current_hole;
    if (delta < 0) delta += HOLE_COUNT;

    // 第一版建议固定单方向转，避免机械回差影响
    for (int i = 0; i < delta; i++) {
        move_one_hole(true);
    }
    current_hole = target;
}

bool home_sensor_active(void) {
    return READ_HOME_SENSOR() == 1;
}

void wheel_home(void) {
    // 1. 先离开HOME区域，防止开机正好压在传感器上
    for (int i = 0; i < 300 && home_sensor_active(); i++) {
        move_pulses(1, true, 80);
    }

    // 2. 慢速寻找HOME
    int timeout = 4000;
    while (!home_sensor_active() && timeout-- > 0) {
        move_pulses(1, false, 80);
    }
    if (timeout <= 0) {
        report_error(HOME_TIMEOUT);
        return;
    }

    // 3. 反向退出，再更慢速二次靠近，取边沿更准
    move_pulses(30, true, 80);
    while (!home_sensor_active()) {
        move_pulses(1, false, 40);
    }

    // 4. 走机械偏移，让滤光片1正对黑白相机光轴
    if (home_offset_pulses >= 0) {
        move_pulses(home_offset_pulses, true, 80);
    } else {
        move_pulses(-home_offset_pulses, false, 80);
    }

    current_hole = 1;
}

11. 与电脑的控制命令

电脑通过USB串口给STM32发命令；电脑自己控制两个相机，STM32只负责转轮、电机、灯、风扇、门和状态返回。为了简单，电机部分可以沿用6字节固定帧：

帧格式：AA 55 CMD P1 P2 SUM
SUM = (AA + 55 + CMD + P1 + P2) & 0xFF
命令 CMD P1 P2 STM32动作
转轮HOME 0x02 0 0 执行wheel_home()，成功后返回当前孔位=1。
转到指定孔 0x03 1-16 速度档：0慢/1中/2快 转到目标孔位，停稳后返回OK。
下一个孔 0x04 0 速度档 当前孔位+1，超过16回到1。
读取状态 0x0C 0 0 返回当前孔位、HOME状态、驱动器报警、电源/温度状态。
急停 0xFF 0 0 停止发脉冲，关闭灯，保持风扇；必要时切断电机供电。

12. 启动顺序

1上电检查
确认48V、5V、STM32供电正常，HBS57H显示run或无报警。
2关灯启动
卤钨灯和LED默认关闭，防止热量和误曝光。
3风扇先开
驱动器区域和灯区风扇先运行。
4转轮HOME
低速找原点，二次靠近，走offset对准孔1。
5等待采集
电脑控制相机，STM32按命令切换孔位。

13. 单次多光谱采集流程

  1. 电脑发送0x02，STM32执行HOME。
  2. 电脑让黑白相机准备采集，关闭RGB灯。
  3. 电脑发送0x03, P1=1，转到第1个滤光片孔位。
  4. STM32转动完成后等待500-1000ms，返回OK。
  5. STM32打开卤钨灯，预热/稳定1-3s，电脑触发黑白相机曝光。
  6. 拍完后关闭或保持卤钨灯，转到下一个滤光片孔位。
  7. 重复16个孔位，得到一组多光谱图像。
  8. 关闭卤钨灯，打开RGB LED，电脑采集RGB图像。
  9. 全部采集完成后关灯，风扇延时运行。

建议：第一版可以每个孔位“转到位 - 停1秒 - 拍照”，这样容易排查错位、抖动和光照稳定问题。后期再把停顿缩短。

15. 常见问题

15.1 可以不用信号升压模块，STM32直接接吗？

不建议作为正式方案。HBS57H的控制端支持5V-24V，手册逻辑输入电流典型约10mA；STM32 GPIO是3.3V，单脚驱动能力有限。直接接有时能动，但抗干扰和长期稳定性差。建议用3.3V输入、5V输出的高速隔离/差分模块。

15.2 HBS57H内部有原点功能，要不要用？

第一版不建议用驱动器内部原点/多段位功能。它虽然能做原点和内部位置模式，但会让“电脑-STM32-相机”的状态同步变复杂。更简单可靠的方式是：HOME传感器接STM32，由STM32发脉冲并维护当前孔位。

15.3 用固定方向转还是最短路径转？

第一版建议固定一个方向转。固定方向可以避开齿隙、轴承间隙和转轮装配回差带来的重复定位问题。等机械结构稳定后，再考虑最短路径。

15.4 48V会不会更热？

在同样低速和同样电流设置下，48V不是必然明显更热；发热主要取决于电流、保持时间、散热和负载。48V的好处是动态余量更大。你的转轮低速运行，建议通过P-01把保持电流先设低一些，并给驱动器附近留风扇。

HBS57H到电机A/B相 A+、A-、B+、B-按配套线缆接 使用电机配套动力线
HBS57H到编码器 EA±、EB±、VCC、EGND按配套线缆接 使用屏蔽编码器线
STM32到转换模块 STEP、DIR、GND，ENA可选 0.2-0.3mm²信号线，短线即可
转换模块到HBS57H PUL±、DIR±，ENA±可选 屏蔽双绞线更好
HOME传感器到STM32 5V传感器可直接转3.3V输入；24V传感器需隔离 0.2-0.3mm²信号线
ALM报警到STM32 通过光耦输入模块读取 0.2-0.3mm²信号线

最后检查清单：48V正负极确认；PUL/DIR信号电压确认；电机线和编码器线确认；HOME传感器不会输出24V直进STM32；首次运行不要装滤光片，先空转转轮；确认每次100脉冲准确转过一个孔位后，再安装滤光片。
