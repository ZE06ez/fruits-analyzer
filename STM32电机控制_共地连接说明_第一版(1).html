STM32电机控制——共地连接说明

第一版配置：STM32F407（电脑USB供电）＋ DST-1R4P-D（LM2596提供5V）＋ HBS57H ＋ 57闭环步进电机。

一句话结论：只在各自功能区域内部共地。STM32输入侧、24V/DST供电侧、48V电机侧和12V灯具侧之间不额外并接直流负极；三台开关电源的PE保护地和金属机箱则统一接保护地。

1. 哪些引脚必须连接在一起

地电位区域必须连接说明
STM32信号输入侧STM32 GND → DST 1−
STM32 GND → DST 2−		1−和2−都以STM32 GND为3.3V信号参考；PA8接1+，PA9接2+。
24V/5V模块供电侧LRS-250-24 V− → LM2596 IN−
LM2596 OUT− → DST GND		LM2596为非隔离降压模块，通常IN−与OUT−内部相通，因此这些端子属于同一地电位区域。
48V电机动力侧LRS-200-48 V− → HBS57H GND只作为HBS57H主电源负极，不接STM32 GND。
编码器回路电机编码器GND → HBS57H EGND使用配套编码器线；EGND是编码器专用地，不要擅自接到48V GND。
12V灯具回路LRS-400-12 V− → 两路灯具控制回路负极保持在灯具区域内，不接STM32 GND或48V GND。
保护地PE三台开关电源PE、金属机箱、金属安装板PE是安全保护地，不是STM32信号GND。

3. 第一版明确禁止的连接

  • 不要连接 STM32 GND 与 DST-1R4P-D供电端GND。输入通过1−、2−引用STM32 GND，输出侧由光耦隔离。
  • 不要连接 HBS57H主电源GND与STM32 GND或DST供电GND。
  • 不要连接 LRS-400-12 V−、LRS-250-24 V−、LRS-200-48 V−三路直流负极。
  • 不要连接 HBS57H EGND与48V主电源GND；EGND只按配套编码器线连接。
  • 不要把 PE保护地当成5V/12V/24V/48V直流负极使用。

4. 实际接线清单

LRS-250-24 V−  → LM2596 IN−
LM2596 OUT−     → DST-1R4P-D GND
LM2596 OUT+     → DST-1R4P-D VCC（先调至5.00V）

STM32 GND       → DST-1R4P-D 1−
STM32 GND       → DST-1R4P-D 2−
STM32 PA8       → DST-1R4P-D 1+
STM32 PA9       → DST-1R4P-D 2+

DST A+ / A−     → HBS57H PUL+ / PUL−
DST B+ / B−     → HBS57H DIR+ / DIR−
控制信号只接差分对，不额外接GND

LRS-200-48 V−   → HBS57H GND
编码器GND       → HBS57H EGND（仅用配套编码器线）
万用表检查：断电状态下，LM2596 IN−与OUT−通常导通；STM32 GND与DST供电GND应保持隔离；48V GND、24V V−和12V V−之间不应由你额外接线短接。
