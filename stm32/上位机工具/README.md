# HBS57H + STM32F407ZGT6 匀速旋转测试

## 一、模块接线顺序(全部断电操作,先接线后上电)

### 第 1 步:220V 交流侧
三台开关电源的 `L / N` 接同一组 220V 配电,**先不接任何负载**:
- `LRS-200-48`(48V/4.2A)→ 只给 HBS57H 主电源
- `LRS-250-24`(24V/10A)→ 给 LM2596 降压模块
- `LRS-400-12`(12V/33A)→ 卤钨灯(本测试不用)
- 三台电源金属外壳 `PE` 全部接保护地

### 第 2 步:48V → HBS57H
| 来源 | 接到 | 说明 |
|---|---|---|
| LRS-200-48 `V+` | HBS57H `+VDC` | 先用万用表确认正负极再上电 |
| LRS-200-48 `V-` | HBS57H `GND` | 不要接到控制信号端子 |

**此步暂不接电机。**

### 第 3 步:24V → LM2596 → 5V → DST-1R4P-D
| 来源 | 接到 | 说明 |
|---|---|---|
| LRS-250-24 `V+` / `V-` | LM2596 `IN+` / `IN-` | 输入极性一一对应,**严禁接 48V** |
| LM2596 `OUT+` | DST-1R4P-D `VCC` | 先空载把输出调成 5.00V 再接 |
| LM2596 `OUT-` | DST-1R4P-D `GND` | 模块供电侧地 |

### 第 4 步:STM32 → DST-1R4P-D(输入侧)
| STM32 | DST-1R4P-D | 信号 |
|---|---|---|
| `PA8`(TIM1_CH1) | `1+` | STEP 脉冲 |
| `GND` | `1-` | 第 1 路参考地 |
| `PA9` | `2+` | DIR 方向 |
| `GND` | `2-` | 第 2 路参考地 |

### 第 5 步:DST-1R4P-D(输出侧)→ HBS57H 控制端子
| DST-1R4P-D | HBS57H | 信号 |
|---|---|---|
| `A+` | `PUL+` | 脉冲正 |
| `A-` | `PUL-` | 脉冲负 |
| `B+` | `DIR+` | 方向正 |
| `B-` | `DIR-` | 方向负 |

**HBS57H 的 `ENA+` / `ENA-` 悬空**(手册建议一般情况悬空即可)。

### 第 6 步:HBS57H → 57 闭环电机
- 动力线:`A+` / `A-` / `B+` / `B-` **严格按电机配套线缆/标签颜色接**,不要猜颜色
- 编码器线:EA±、EB±、`VCC`、`EGND` 接配套屏蔽线,由驱动器供电
- **禁止带电插拔动力线和编码器线**

### 第 7 步:驱动器面板参数(上电后设置,改完断电重启)
| 功能码 | 建议值 | 含义 |
|---|---|---|
| P-00 | 1600 | 细分脉冲数/圈(出厂即 1600,确认即可) |
| P-08 | 0 | 脉冲+方向模式 |
| P-09 | 0 | 外部脉冲模式 |
| P-18 | 1 | 闭环模式 |
| P-25 | 1 | 平滑滤波使能(出厂是 0,要改) |
| P-12 | 0/1 | 方向,转反了再调 |

### 第 8 步:上电顺序
1. 合上 220V 交流电源 → 驱动器数码管应显示 `run`(电机锁住),无 Er 报警
2. 先用手轻轻拧电机轴,应能感到锁力
3. 电脑 USB 给 STM32 供电(第一版 STM32 由 USB 供电,不接 24V)
4. 烧录程序后自动开始匀速旋转

## 二、程序说明

- 文件:`main.c`(HAL 库,替换 CubeMX 生成工程的 main.c,保留 main.h)
- 引脚:PA8 = STEP(TIM1_CH1),PA9 = DIR
- 默认 400Hz 脉冲 → 1600 脉冲/圈 → **0.25 圈/秒(15rpm)**,慢速稳妥
- 改动两个宏即可:
  - `PULSE_HZ` 调速度(如 100Hz → 0.06 圈/秒)
  - `DIR_FORWARD_LEVEL` 调方向,或改驱动器 P-12
  - `AUTO_REVERSE_MS` 设成 >0 可自动换向,验证 DIR 接线

## 三、验证要点

- 驱动器显示 `run` 无报警 → 接线正确
- 方向反了 → 改 `DIR_FORWARD_LEVEL` 或 P-12,二选一
- 电机不转但有锁力 → 检查 PA8 是否复用 TIM1、驱动器 P-08/P-09 是否为 0
- 怀疑丢步 → 面板 L-05(接收脉冲数)应持续累加,L-06(反馈脉冲数)应基本一致
