# HBS57H 上位机通信协议(STM32 固件 v1)

> 串口:115200-8N1-无流控。板载 CH340 或外部 TTL 模块接 **USART1(PA9=TX, PA10=RX)**。
> 上位机参考实现:`C:\Users\林~\ZCodeProject\HBS57H_STM32\hbs57h_protocol.py`(Python)

## 1. 帧格式(统一)

```
┌──────┬──────┬─────┬──────┬──────────────────┬──────┬──────┐
│ 0xAA │ 0x55 │ CMD │ PLEN │  PAYLOAD[0..n)  │ CRCH │ CRCL │
└──────┴──────┴─────┴──────┴──────────────────┴──────┴──────┘
  帧头×2   命令字   载荷长度  载荷数据(PLEN字节)  CRC高字节 CRC低字节
```

- **PLEN**:载荷字节数(0~32)
- **多字节数据一律小端序**(低字节在前),float 为 IEEE754 单精度
- **CRC 高字节在前发送**

## 2. CRC16 校验规则(CRC16-CCITT-FALSE)

- 多项式:`0x1021`(x¹⁶+x¹²+x⁵+1)
- 初值:`0xFFFF`,不取反、不异或
- **覆盖范围:从 CMD 字节到 PAYLOAD 最后一个字节**(不含帧头 AA 55,不含 CRC 本身)
- 发送方计算后拆成高/低字节放入帧尾;接收方用相同算法重算,与收到的 CRC 比对,不一致则丢弃并回 ACK(result=1)

### 算法(C 语言,固件 comm.c 同款)

```c
static uint16_t crc16_byte(uint16_t crc, uint8_t b)
{
  crc ^= (uint16_t)b << 8;
  for (uint8_t i = 0; i < 8; i++)
    crc = (crc & 0x8000u) ? ((crc << 1) ^ 0x1021u) : (crc << 1);
  return crc;
}
// 计算一帧: crc = 0xFFFF; crc = crc16_byte(crc, CMD); crc = crc16_byte(crc, PLEN);
//          for i in 0..PLEN: crc = crc16_byte(crc, PAYLOAD[i]);
```

### 标准测试向量

- 字符串 `"123456789"` 的 CRC16-CCITT-FALSE = **0x29B1**(用于自检算法实现)

### 示例:QUERY_STATUS 命令 `AA 55 08 00 94 A6`

CRC 计算覆盖 `[0x08, 0x00]`:
```
crc=0xFFFF
  byte 0x08: crc=0xF00D  → 0x... (逐步移位异或)
  byte 0x00: ...
最终 crc = 0x94A6 → 发送顺序: 0x94(高) 0xA6(低)
```

### 示例:MOVE_ABS(90°, 30rpm) 完整帧

```
AA 55 01 08  00 00 B4 42  00 00 F0 41  44 41
        │    └─ 90.0f LE ─┘ └─ 30.0f LE ─┘ │
        └── CMD=0x01      └─ CRC=0x4144 ──┘
```

## 3. 命令(PC → MCU)

| CMD | 名称 | PLEN | 载荷(小端序) | 说明 |
|---|---|---|---|---|
| 0x01 | MOVE_ABS | 8 | float 角度°, float 转速rpm | 绝对角度匀速到达 |
| 0x02 | MOVE_REL | 8 | float 角度°, float 转速rpm | 相对当前方向叠加 |
| 0x03 | STOP | 0 | - | 减速停止 |
| 0x04 | SET_POS_PID | 12 | float Kp, Ki, Kd | 位置环参数,立即生效 |
| 0x05 | SET_VEL_PID | 8 | float Kp, Ki | 速度环参数,立即生效 |
| 0x06 | SET_PROFILE | 12 | float max_rpm, acc, dec | 速度上限/加速度/减速度(pps/s) |
| 0x07 | SET_CONFIG | 4 | float ppr | 每转脉冲数(200~60000) |
| 0x08 | QUERY_STATUS | 0 | - | 立即回一帧 0x81 |
| 0x09 | SET_ORIGIN | 0 | - | 当前位置清零 |
| 0x0F | RESET | 0 | - | 软复位 |
| 0x10 | FAN_SET | 1 | u8 占空比% | 风扇:0=关,100=满速 |
| 0x11 | DOOR_SET | 1 | u8 命令 | 升降门:0=升起(缩回) 1=关闭(伸出) 2=停止 |
| 0x12 | LED_SET | 1 | u8 位掩码 | 三路 LED:bit0=LED1 bit1=LED2 bit2=LED3(全开=0x07) |
| **0x10** | **FAN_SET** | **1** | **u8 占空比%** | **散热风扇 PWM:0=关,100=满速(20kHz,PB6→YYNMOS-4 PWM4)** |

### 参数约束

- 角度:`±100000°`
- 转速:`0.5 ~ 500 rpm`。**超过 500rpm → result=3 拒绝执行**(硬限幅)
- SET_PROFILE:max_rpm `1~500`,acc/dec `100~100000 pps/s`
- FAN_SET:占空比 `0~100`
- 运动中被命令打断(正在转时收到新 MOVE)→ `result=4(BUSY)`

## 4. 应答(MCU → PC)

### 4.0 短帧协议(风扇/LED,接线文档同款,无 CRC 无帧头)

PC 直接发 2 字节命令,MCU 执行后回 2 字节应答(HEX 串口助手可手输):

| 命令 | 含义 | 应答 |
|---|---|---|
| `10 00` | 关风扇 | `90 00` |
| `10 01` | 开风扇(满速) | `90 00` |
| `11 00` | 升降门:升起(推杆缩回) | `91 00` |
| `11 01` | 升降门:关闭(推杆伸出) | `91 00` |
| `11 02` | 升降门:立即停止(刹车) | `91 00` |
| `12 00` | 三路 LED 全关 | `92 00` |
| `12 01` | 只开 LED1 | `92 00` |
| `12 02` | 只开 LED2 | `92 00` |
| `12 04` | 只开 LED3 | `92 00` |
| `12 03` | LED1+LED2 | `92 00` |
| `12 07` | 三路 LED 全开 | `92 00` |

> LED 掩码为 3 位:bit0=LED1,bit1=LED2,bit2=LED3;值必须 0~7,非法值不回。
> 风扇 `10` 后接 0x02~0x64 为占空比扩展(按 % 调速,0x01=100% 与文档一致)。
> 推杆 `11` 后接 0~2,非法值不回;换向时固件自动先刹车 ≥100ms 再驱动;单次连续动作超时 **28s** 自动停机。2026-09-05 当前机构分段实测:伸出有效运动约19s、缩回约20s,可按单程约20s估算。
>
> `91 00` 只表示命令已被接受,不表示到达端点。PC3/PC4 外部限位仍为预留,当前固件不能读取推杆位置或端点。分段发送“停止→同方向启动”会重新开始28s计时,不能把该超时当作累计运行保护。
> 短帧与 AA55 二进制帧/ASCII 文本**自动共存**,互不干扰(帧头 AA/55 或帧内字节不进入短帧解析)。

### 4.1 ACK(0x80)——所有命令的确认

```
AA 55 80 02  ECHO  RESULT  CRCH CRCL
             └── 回显原CMD ─┘
```

| RESULT | 含义 |
|---|---|
| 0 | OK,命令已执行 |
| 1 | CRC 校验失败 |
| 2 | 未知命令 |
| 3 | 参数超范围 |
| 4 | 忙(电机运动中) |

### 4.2 STATUS(0x81)——状态帧,每 100ms 自动发送;QUERY_STATUS 也触发

```
AA 55 81 12  STATE ERR POS[0..3] VEL[0..3] TGT[0..3] FAN LED1 LED2 LED3 CRCH CRCL
             └1B┘ └1B┘ └─float──┘ └─float──┘ └─float──┘ └1B┘└1B┘ └1B┘ └1B┘
```

| 偏移 | 字段 | 类型 | 说明 |
|---|---|---|---|
| 0 | STATE | u8 | 0=空闲 1=运动中 2=减速停 3=已到位 |
| 1 | ERR | u8 | 0=正常(预留) |
| 2-5 | POS | float | 当前角度 °(脉冲计数换算,1 脉冲=0.225°@1600ppr) |
| 6-9 | VEL | float | 当前速度 rpm |
| 10-13 | TGT | float | 目标角度 ° |
| 14 | FAN | u8 | 风扇占空比 %(0=关,100=满速) |
| 15 | LED1 | u8 | LED1 占空比 %(0=灭,100=亮) |
| 16 | LED2 | u8 | LED2 占空比 % |
| 17 | LED3 | u8 | LED3 占空比 % |

### 4.3 INFO(0x82)——上电发一帧

```
AA 55 82 0D  VER PPR[0..3] MAXRPM[0..3] ACC[0..3] CRCH CRCL
             └1B┘└─float──┘└──float────┘└─float───┘
```

| 字段 | 说明 |
|---|---|
| VER | 固件版本(当前 1) |
| PPR | 每转脉冲数(默认 1600) |
| MAXRPM | 速度上限(默认 500) |
| ACC | 加速度 pps/s(默认 2500) |

## 5. ASCII 文本协议(人工上位机验证,与二进制自动共存)

字节流同时喂两个解析器(二进制帧 + 文本行),各自校验互不干扰。
文本行以回车/换行结尾(串口助手直接输入即可)。

| 方向 | 内容 | 说明 |
|---|---|---|
| MCU→PC | `ready` | 上电每 0.5s 检查电机状态,**正常后只发一次** |
| PC→MCU | `EN` | 电机使能,保持当前角度 → 回 `EN_OK` |
| PC→MCU | `MOVE deg rpm` | 相对移动 deg°、速度 rpm(如 `MOVE 10 100`)→ 执行完回 `MOVE_OK` |
| PC→MCU | `FAN pct` | 风扇占空比 0~100(如 `FAN 100` 满速)→ 回 `FAN_OK`/`FAN_ERR` |
| PC→MCU | `LED mask` | 三路 LED 位掩码 0~7(如 `LED 7` 全开)→ 回 `LED_OK`/`LED_ERR` |
| PC→MCU | `DOOR cmd` | 升降门 0=升起 1=关闭 2=停止(如 `DOOR 1`)→ 回 `DOOR_OK`/`DOOR_ERR` |
| PC→MCU | `STOP` | 减速停止 → 回 `STOP_OK` |

错误:参数越界 / 未先 EN / 电机忙 → 回 `MOVE_ERR`。
MOVE 的 rpm 同样受 500rpm 硬限幅约束。

## 6. 状态机说明(STATE)

```
0 IDLE  ──收到MOVE──► 1 MOVING ──到位──► 3 DONE
   ▲                    │  │
   │                    │  └──收到STOP──► 2 STOPPING ──减速到0──► 0 IDLE
   └──(命令时不可打断,回BUSY)
```

- 运动中途收到新 MOVE 命令 → **拒绝并回 result=4**,需先 STOP 或等到位
- 断电重启后位置归零;手动对好零点后发 0x09(SET_ORIGIN)

---

## 7. 速度限幅说明

- **协议层**:MOVE 命令转速 > 500 rpm → 拒绝(result=3)
- **控制层**:运动速率精确钳位在命令值(无 PID 超速裕量)
- **脉冲层**:TIM2 中断里再钳一道硬上限 `500rpm×(PPR/60)pps`,任何路径都无法超速
