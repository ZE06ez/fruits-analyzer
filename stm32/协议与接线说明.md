# HBS57H 闭环步进电机 —— 串口角度/速度控制固件说明

## 一、接线变化(相对上一版"匀速旋转")

| 信号 | 上一版 | 本版 | 说明 |
|---|---|---|---|
| STEP | PA8 | **PA8(不变)** | 现在由 TIM2 中断翻转,仍是 DST-1R4P-D 的 1+ |
| DIR | PA9 | **PC6(要挪一根线)** | PA9 让给串口 TX;DIR 改接 PC6 → 模块 2+ |
| 串口 TX | - | **PA9 = USART1_TX** | 接板载 CH340 的 RX(板上通常已连好) |
| 串口 RX | - | **PA10 = USART1_RX** | 接板载 CH340 的 TX |
| 电源/驱动/电机 | 不变 | 不变 | 48V、DST 模块、HBS57H、电机接线全部不动 |

**你只需要做一件事**:把 DIR 那根线从 PA9 挪到 PC6(接 DST-1R4P-D 的 2+ 不变)。然后板子 USB 插电脑 = COM35 串口。

> 如果你板子的 CH340 不是接在 USART1(PA9/PA10),告诉我,我改到别的串口(UART3/USART2),接线再给你。

## 二、串口参数

- 115200, 8N1, 无流控
- 上位机 = 电脑串口助手(选 HEX 发送)或 `hbs57h_protocol.py`

## 三、协议(帧格式)

```
AA 55 CMD PLEN [PAYLOAD...] CRCH CRCL
```
- **CRC16-CCITT-FALSE**(poly 0x1021, init 0xFFFF),覆盖 `CMD..PAYLOAD`(不含 AA 55)
- CRC 高字节在前
- 多字节 = **小端序**
- 校验失败 → MCU 回 `ACK, result=1`

### PC → MCU 命令

| CMD | 名称 | PLEN | 载荷 | 说明 |
|---|---|---|---|---|
| 0x01 | MOVE_ABS | 8 | float 角度°, float 转速 rpm | 绝对角度匀速到达 |
| 0x02 | MOVE_REL | 8 | float 角度°, float 转速 rpm | 相对当前转 |
| 0x03 | STOP | 0 | - | 减速停止 |
| 0x04 | SET_POS_PID | 12 | float Kp, Ki, Kd | 位置环参数实时修改 |
| 0x05 | SET_VEL_PID | 8 | float Kp, Ki | 速度环参数实时修改 |
| 0x06 | SET_PROFILE | 12 | float max_rpm, acc, dec | 速度上限/加速度/减速度 |
| 0x07 | SET_CONFIG | 4 | float ppr | 每转脉冲数(改驱动 P-00 后同步) |
| 0x08 | QUERY_STATUS | 0 | - | 立即回一帧 STATUS |
| 0x09 | SET_ORIGIN | 0 | - | 当前位置清零 |
| 0x0F | RESET | 0 | - | 软复位 |

### MCU → PC 应答

| CMD | 名称 | PLEN | 载荷 |
|---|---|---|---|
| 0x80 | ACK | 2 | u8 回显CMD, u8 result(0=OK,1=CRC,2=未知命令,3=参数错,4=忙) |
| 0x81 | STATUS | 14 | u8 state, u8 err, float pos_deg, float vel_rpm, float target_deg |
| 0x82 | INFO | 13 | u8 版本, float ppr, float max_rpm, float acc(上电发一次) |

state: 0=空闲 1=运动中 2=减速停 3=已到位。STATUS 每 100ms 自动发一帧。

## 四、内置 PID 参数(仿真调优,可串口实时改)

```
位置环: Kp=8.0  Ki=0.2  Kd=0.0   修正量限幅 300pps
速度环: Kp=0.8  Ki=8.0           输出限幅 400pps
加减速: 2500 pps/s               (到 60rpm 约 0.6 秒)
速度上限: 500 rpm(硬限幅,超过命令被拒;另有 0x06 SET_PROFILE 可调)
细分:   P-00 = 1600(与驱动器面板一致,可 0x07 改)
```

## 五、测试方法

### 方式 A:串口助手(HEX 发送)
发 `AA 55 01 08 00 00 B4 42 00 00 F0 41 44 41` = 转到 90°、30rpm。
(更多示例帧见 `C:\Users\林~\ZCodeProject\HBS57H_STM32\hbs57h_protocol.py`)

### 方式 B:Python 脚本(推荐)
```bash
pip install pyserial
python hbs57h_protocol.py                 # 自检 CRC 与编码
python hbs57h_protocol.py --port COM35 move 90 30     # 转90度@30rpm
python hbs57h_protocol.py --port COM35 move 22.5 10   # 一个孔位
python hbs57h_protocol.py --port COM35 status         # 查询状态
python hbs57h_protocol.py --port COM35 pid 12 0.5 0.1 # 改位置环PID
python hbs57h_protocol.py --port COM35 stop
```

## 六、预期行为

1. 上电:回一帧 INFO,然后每 100ms 回 STATUS
2. 发 MOVE_ABS(90, 30):电机加速 → 30rpm 匀速 → 减速 → 精确停在 90°,STATUS 显示 state=3
3. 转的是绝对角度,20°→360° 会转一整圈多;发 SET_ORIGIN 重新定零点
4. 烧录前先把滤光片取下,空转验证;第一次建议转速 ≤30rpm

## 七、注意

- 第一次烧录后**断电重启一次**(让新固件跑起来)
- 转动时驱动器显示 run;报 Er05(位置超差)= 转速/加速度太大,用 0x06 调小
- 电机断电重启后位置回到 0(无编码器记忆);每次开机手动对好 1 号孔再发 SET_ORIGIN
- 模块化设计:pid.c/motor.c/comm.c 各自独立,以后加外部编码器只改 motor.c 的反馈函数
