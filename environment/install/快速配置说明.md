# STM32F407 新电脑快速配置说明

本目录用于借助可移动硬盘，在另一台 Windows 10/11 x64 电脑上快速配置 `fruits-analyzer` 工程的 STM32F407 编译、DAPLink烧录、GDB调试和串口测试环境。

## 重要结论

- 不需要安装 Keil 5：当前仓库的固件工程采用 CMake + Ninja + GNU Arm GCC。
- 本离线包已经包含完成核心工作所需的编译器、构建工具、OpenOCD、Python、串口依赖和 `STM32` 分支源码。
- STM32CubeCLT和STM32CubeMX不是编译现有源码的必需项。需要修改 `.ioc` 或使用ST官方集成工具时再另行安装。
- DAPLink只连接TX、RX、VCC、GND时只能进行串口通信，不能烧录和断点调试；烧录必须连接SWD。
- 不要使用Zadig随意替换DAPLink驱动，尤其不能替换DAPLink的CDC串口接口。

## 最快配置顺序

在目标电脑上进入本目录的 `scripts`，依次运行：

1. `00_verify_package_hashes.cmd`
2. `01_install_apps.cmd`
3. 关闭旧终端并重新打开终端。
4. `02_extract_tools.cmd`
5. `04_verify_env.cmd`
6. `05_install_pyserial.cmd`
7. `06_deploy_source.cmd`
8. `07_build_debug.cmd`
9. 如果安装了VS Code，可运行 `09_install_vscode_extensions.cmd`。
10. 确认硬件接线和现场安全后，才可运行 `08_flash_daplink.cmd`

`03_stm32_shell.cmd` 可随时打开已经注入GNU Arm、OpenOCD和Ninja路径的专用CMD终端。便携工具默认解压到：

```text
%LOCALAPPDATA%\STM32-Tools
```

源码默认解压到：

```text
%USERPROFILE%\STM32-Workspace\fruits-analyzer-STM32
```

脚本遇到已有源码目录时会停止，不会覆盖现有文件。

## 安装界面需要选择的选项

### Git

一般保留默认选项即可，确保Git可从CMD中运行。

### CMake

安装时选择将CMake加入PATH。安装后必须重新打开终端。

### Python

勾选“Add python.exe to PATH”。安装完成后重新打开终端，再安装离线的pyserial。

### VS Code

VS Code是可选项，不影响命令行编译和烧录。需要图形化代码编辑、断点调试时建议安装。

## DAPLink烧录接线

| DAPLink | STM32F407 |
|---|---|
| SWDIO | PA13 |
| SWCLK | PA14 |
| GND | GND |
| 3.3V/Vref | 目标板3.3V参考 |
| NRST（建议） | NRST |

注意：

- 3.3V/Vref是逻辑电平参考，不能用5V代替。
- TX/RX不是SWD烧录线；串口与SWD是两条不同的数据链路。
- 串口接线为DAPLink TX → STM32 PA10、DAPLink RX → STM32 PA9，并且GND共地。
- 初次烧录前断开钨灯及12V电源、推杆电机、步进电机、风扇等大功率负载。

## 烧录命令说明

安全确认后，脚本使用：

```cmd
openocd -f interface/cmsis-dap.cfg -f target/stm32f4x.cfg -c "adapter speed 1000" -c "program build/Debug/zhunong.hex verify reset exit"
```

只有OpenOCD日志明确显示program、verify和reset完成，才能判定烧录成功。如果无法连接，先降低速度并检查SWD接线、目标板供电和DAPLink枚举情况，不要直接更换USB驱动。

## STM32CubeCLT和CubeMX

本包使用独立GNU Arm、CMake、Ninja和OpenOCD完成现有工程的编译与DAPLink烧录，因此不依赖STM32CubeCLT。

如需安装ST官方整合工具，可从以下页面获取：

- STM32CubeCLT：<https://www.st.com/en/development-tools/stm32cubeclt.html>
- STM32CubeMX：<https://www.st.com/en/development-tools/stm32cubemx.html>

ST官网下载可能要求MyST登录、邮箱验证和许可确认，因此安装包未自动放入本目录。它们是修改或重新生成CubeMX工程时的可选扩展，不影响当前源码的离线编译。
